# FUTURE_FS_03 — Local Business Website & Live Pitch

## Project concept
A sample website for "Olive & Ember", a fictional neighborhood restaurant. This is a demonstration concept; it is not a real business.

## Features
- Responsive restaurant landing page
- Story, menu highlights, opening hours, contact information
- Mobile navigation
- Table enquiry form with client-side validation and demo confirmation
- SEO description and clear calls to action

## Run
Open `index.html` in a browser, or use VS Code Live Server. The hero image is loaded from Unsplash and requires an internet connection.

## Important before pitching
1. Choose a real local business and ask permission before representing it.
2. Replace the fictional business name, menu, prices, address, phone number, hours, and imagery with verified details.
3. The enquiry form is a front-end demo and does not send bookings. Add a backend or form service if the owner needs live enquiries.
4. Prepare a short pitch explaining how the site helps customers find the business, view services/menu, and contact the owner.
5. Publish the source in the repository `FUTURE_FS_03` or provide the approved website-builder link.

## Suggested pitch outline
- Business challenge: customers need one place to see key information.
- Proposed solution: mobile-friendly website with services/menu, location, hours and contact CTA.
- Business benefit: easier discovery, clearer information and a simple path to enquire.
- Demo: show the site on desktop and mobile and explain what can be customized.
